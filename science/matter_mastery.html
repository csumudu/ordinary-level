3Elements & their symbols

Elements: the un-splittable substances

An element is a pure substance that cannot be broken down into simpler substances by any physical or chemical method. About 120 elements have been discovered. Examples: iron, sulphur, chlorine, silver, zinc, copper, carbon, oxygen, aluminium, mercury.

Symbols — a global shorthand

Every country uses the same symbols for elements. There are three rules for where a symbol comes from:

① One capital letter

First letter of the English name (always capital).
C=Carbon · O=Oxygen · S=Sulphur · H=Hydrogen

② Two letters

When names share a first letter, add a second (lowercase).
Cl=Chlorine · Ca=Calcium · Mg=Magnesium · Al=Aluminium

③ From Latin names

Some come from the Latin name, not English.
Na=Sodium (Natrium) · Fe=Iron (Ferrum) · Au=Gold (Aurum)

The #1 careless mistakeIn a two-letter symbol, only the first letter is capital. It's Cl not CL, Na not NA. Co (cobalt) and CO (carbon monoxide, a compound) mean totally different things!
4Building units

Atoms & molecules

Matter is made of incredibly tiny particles. John Dalton named the smallest indivisible particle an atom (from the Greek atomos = "cannot be divided"). An element is made of atoms that are all the same type — iron atoms differ from aluminium atoms.

What's a molecule?

A molecule is a unit made when one or more atoms combine. When the joined atoms are the same kind, it's a homo-atomic molecule. Oxygen doesn't float around as single O atoms — it pairs up as O₂.

Gallery · Homo-atomic vs hetero-atomic molecules

The key distinctionHomo-atomic = same atoms → still an element (O₂, H₂, N₂, Cl₂, F₂). Hetero-atomic = different atoms → a compound (H₂O, CO₂, HCl, NH₃, CH₄).
5Inside the atom

Atomic structure — build your own atom

An atom is mostly empty space! Almost all its mass sits in a tiny, positively-charged core called the nucleus (discovered by Ernest Rutherford). Three subatomic particles make up every atom:

6Atomic & mass number

The two numbers that define an atom

Atomic number (Z)

= the number of protons in the nucleus. It's the atom's unique fingerprint — no two elements share the same Z. Since atoms are neutral, Z = protons = electrons.

Mass number (A)

= protons + neutrons (the heavy particles in the nucleus). So the number of neutrons = A − Z.

How to read the standard notation

Mass number goes top-left, atomic number goes bottom-left of the symbol. Pick an atom to decode it:

Decoder · ᴬZX notation

Memory hook: A is Above (top), and A is the bigger number (mass). Neutrons = A − Z (mass minus protons). Example: ²³11Na → 11 protons, 11 electrons, 23−11 = 12 neutrons.
7Compounds

Compounds: elements chemically joined

A compound forms when two or more different elements combine chemically in a fixed ratio. Their molecules contain different atoms, so they're hetero-atomic molecules. A compound's chemical formula tells you which atoms and how many.

CompoundFormulaElements inside
WaterH₂OH and O
GlucoseC₆H₁₂O₆C, H and O
MethaneCH₄C and H
Carbon dioxideCO₂C and O
Sodium chloride (salt)NaClNa and Cl
Copper sulphateCuSO₄Cu, S and O
Calcium carbonateCaCO₃Ca, C and O
The big idea that surprises studentsThe same set of elements can build completely different compounds with different properties. C and H alone give: methane CH₄ (biogas), hexane C₆H₁₄ (solvent), benzene C₆H₆, acetylene C₂H₂ (welding gas), ethene C₂H₄ (makes polythene). Same ingredients, different recipe → different substance.

Add oxygen (C, H, O) and you get glucose C₆H₁₂O₆, acetic acid CH₃COOH (vinegar), ethanol C₂H₅OH, and sucrose C₁₂H₂₂O₁₁ (cane sugar).

Element vs compound — the clean lineAn element = atoms of one kind. A compound = atoms of two or more kinds, chemically joined in a fixed ratio. The elements inside a compound lose their own properties (sodium is an explosive metal, chlorine a poison gas — together they're table salt!).
8Mixtures

Mixtures & how to separate them

A mixture is two or more pure substances mixed together; the pure substances are its constituents. The defining feature: constituents can be separated by physical methods (no chemistry needed) — because they aren't chemically joined.

9Two kinds of mixture

Homogeneous vs heterogeneous

Mixtures split into two types based on one thing: is it the same all the way through?

🟢 Homogeneous

Uniform throughout — colour and composition are the same everywhere. You can't see separate parts.

salt solutionsugar solutionsea water

🟠 Heterogeneous

Not uniform — composition varies from place to place. You can often see the different parts.

muddy watermortar mixtureice creamfruit salad

Quick testDissolve salt in water → clear and same throughout → homogeneous. Stir clay into water → cloudy, uneven, settles → heterogeneous. "Homo" = same, so homogeneous = looks the same everywhere.

11Last-minute revision

⚡ The night-before cheat sheet

Everything essential, condensed. Skim it the hour before the exam — tap back to any section you're unsure about.

🗺️ Classification of matter

  • Matter → pure substances + mixtures.
  • Pure → elements + compounds.
  • Mixtures → homogeneous + heterogeneous.
  • Pure = one constituent; mixture = two or more.

⚛️ Elements & symbols

  • Element = can't be split further (~120 known).
  • Symbol: 1 capital (C, O, S) or 2 letters (Cl, Ca) — 2nd is lowercase.
  • Latin: Na, Cu, Pb, Au, Hg, Fe, Ag.
  • Homo-atomic molecules: O₂, H₂, N₂, Cl₂, F₂.

🔬 Atomic structure

  • Atom = mostly empty space + tiny nucleus (Rutherford).
  • Proton: nucleus, mass 1, charge +1.
  • Neutron: nucleus, mass 1, charge 0.
  • Electron: around nucleus, mass 1/1840, charge −1.
  • Dalton named the "atom" (atomos = indivisible).

🔢 The two numbers

  • Atomic number Z = protons = electrons. Unique to each element.
  • Mass number A = protons + neutrons.
  • Neutrons = A − Z.
  • Notation: ᴬZX → ²³11Na = 11p, 11e, 12n.

🧪 Compounds

  • 2+ different elements chemically joined, fixed ratio.
  • Hetero-atomic molecules (different atoms).
  • Formulas: H₂O, CO₂, CH₄, NaCl, CuSO₄, CaCO₃, C₆H₁₂O₆.
  • Same elements → different compounds (CH₄ vs C₂H₄).

🥣 Mixtures

  • Separable by physical methods.
  • Methods: winnowing, sifting, panning, distillation, vapourisation, magnets…
  • Homogeneous: uniform (salt solution, sea water).
  • Heterogeneous: non-uniform (muddy water, fruit salad).
Memory hooks:  • Two questions: one or many? then splittable or not?  • Above = mass number A; neutrons = A − Z.  • Protons = the element's identity.  • Homo = same (uniform); hetero = different (patchy).  • Homo-atomic = element; hetero-atomic = compound.
