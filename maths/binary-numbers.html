①Every number is secretly a sum of place values

The numbers you use every day are base ten (decimal). Each digit's spot has a place value that is a power of ten. The digit just says "how many of this place value".

Base ten uses ten digits (0–9) and place values that are powers of ten. But ten isn't magic — we can build the exact same idea on any base. Binary just switches the base to two.

One handy fact we'll use everywhere: any nonzero number to the power 0 equals 1. So 10⁰ = 1, and 2⁰ = 1.

Think of light switches in a row. Each switch is worth a place value (1, 2, 4, 8 …). ON = 1, OFF = 0. To make a number, you flip ON exactly the switches that add up to it. That "which switches are ON" pattern is the binary number. Try it live in the Switch Board below.
Writing the base. To avoid confusion we tag the base as a subscript: 1101two is binary, 603ten is decimal. In this page "₂" means binary.
Going in

③Decimal → Binary (two ways)

Turning an ordinary number into binary. There's a quick way for small numbers and a reliable way for any number.

Way 1 · Sum of powers of two

Pick the biggest powers of two that add up to your number, then mark 1 where used and 0 where not.

13 = 8 + 4 + 1
= 1×2³ + 1×2² + 0×2¹ + 1×2⁰
13 = 1101₂ ✓

Great for small numbers. Fiddly for big ones — that's why we have Way 2.

Way 2 · Divide by 2 repeatedly

Keep dividing by 2, writing the remainder each time, until the quotient is 0. Read the remainders bottom to top.

22 ÷ 2 = 11 r 0
11 ÷ 2 = 5  r 1
5 ÷ 2 = 2  r 1
2 ÷ 2 = 1  r 0
1 ÷ 2 = 0  r 1

Read up ↑ : 22 = 10110₂

Every number has exactly one binary form — there's only one set of distinct powers of two that adds up to it. Use the Converter below to watch Way 2 animate for any number.

Arithmetic

⑤Adding binary — "two makes a carry"

Add column by column from the right, exactly like normal addition. The only new thing: in binary you run out of digits after 1, so 2 becomes a carry.

The only rules you need

1 + 0 = 1
1 + 1 = 10 (write 0, carry 1)
1 + 1 + 1 = 11 (write 1, carry 1)

Example: 101₂ + 1₂

1   
 101
+   1
110

Right column 1+1 = 10 → write 0, carry 1. Next 0+1 = 1. Answer 110₂.

Same as an abacus with a "max of 1 per rod" rule. The moment a rod would hold two beads, you clear it and drop one bead on the rod to its left. That "bump to the left" is the carry.
Arithmetic

⑥Subtracting binary — borrow is worth two

Subtract column by column from the right. When you can't take 1 from 0, borrow from the left — but a borrowed 1 is worth 2 in the column you bring it into.

Example: 110₂ − 1₂

Rightmost column is 0 − 1 — impossible. Borrow the 1 from the 2¹ column; it becomes 2 in the 2⁰ column. Now 2 − 1 = 1, and the 2¹ column is left with 0.

 110
−   1
101

So 110₂ − 1₂ = 101₂.

Always check a subtraction by adding back. 101₂ + 1₂ should give 110₂ — and it does. This catches almost every mistake.
Where it lives

⑦Why binary runs the digital world

A wire is either carrying current or it isn't — on or off. That's naturally two states, so it maps perfectly onto binary's 1 and 0.

💡 Circuits & computers. ON = 1, OFF = 0. A row of lights showing 🔆⚪⚪🔆 stores the number 1001₂ = 9. All storage and computation in computers and calculators is built on this.
🔢 Any base is possible. Base four uses digits 0–3 (decimal 4 = 10₄). Base five uses 0–4 (decimal 5 = 10₅). The place values are just powers of the base.
The pattern to notice: in any base, "10" means "one lot of the base". 10₂ = 2, 10₄ = 4, 10₅ = 5, 10₁₀ = 10. The base is the value that forces a carry to the next column.

⭐ One-glance cheat sheet

Place values (powers of 2)

1, 2, 4, 8, 16, 32, 64, 128 …
each one doubles the last.

Decimal → Binary

Divide by 2 over and over, write remainders, read them bottom to top.

Binary → Decimal

Add the place values sitting above each 1. Zeros add nothing.

Adding

1+1 = 10 (carry 1)
1+1+1 = 11 (carry 1)

Subtracting

Borrow from the left; a borrow is worth 2 in the next column. Check by adding back.

Why 0 & 1

On / off, current / no current — two states, so machines love binary.
