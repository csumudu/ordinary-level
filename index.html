How to use these pages

1

Read once, slowly

Go top to bottom without skipping. Each section is built on the one before it, so the order matters more than the speed.

2

Break the tools

Flip the switches, drag the sliders, feed in odd numbers. The interactive bits are there so you can test your guesses instantly.

3

Answer before revealing

Commit to an answer out loud first, then flip the card or submit the quiz. Guessing then checking is where the learning happens.
